# ITDC 顧客満足度アンケートシステム

Google Apps Script (GAS) で動作する、社内部門向けのアンケート送付・集計システムです。

## 機能

- **アンケート送付** — 宛先リストからオートコンプリートで選択し、アンケートURLをメール送信
- **回答通知** — 回答があった際にオペレーター宛へ即時メール通知（星評価・コメント含む）
- **未回答リマインダー** — 送信から3日経過しても未回答の場合、自動でリマインダーメール送信
- **重複回答ブロック** — 同一URLからの2回目以降の回答を防止
- **自由記述欄** — 星評価5問に加え、任意のコメント欄あり
- **履歴管理** — 全送付・回答データをスプレッドシートで一元管理

## ファイル構成

| ファイル | 役割 |
|---------|------|
| `コード.gs` | サーバーサイドのメイン処理 |
| `index.html` | アンケート送付ツール画面 |
| `form.html` | 回答者向けアンケートフォーム |

## スプレッドシート構成

### 履歴シート（シート名：`履歴`）

| 列 | ヘッダー | 説明 |
|----|---------|------|
| A | ユニークID | 各送付に割り当てられるランダムID |
| B | ステータス | `処理開始` / `リマインダー送信済み` / `回答済み` |
| C | 送信日時 | アンケート送付日時 |
| D | オペレーターID | 送付操作を行ったユーザーのメールアドレス |
| E | 送信先メールアドレス | 回答者のメールアドレス |
| F | 案件名 | 送付時に入力した案件名 |
| G | 回答日時 | 回答が送信された日時 |
| H | 総合満足度 | Q1（1〜5） |
| I | 業務への役立ち度 | Q2（1〜5） |
| J | 説明の分かりやすさ | Q3（1〜5） |
| K | スピード感 | Q4（1〜5） |
| L | 今後の依頼意向 | Q5（1〜5） |
| M | コメント | 自由記述（任意） |

### 宛先リストシート（外部スプレッドシート）

`コード.gs` 内の `sheetId` に別スプレッドシートのIDを指定してください。

| 列 | 内容 |
|----|------|
| A | メールアドレス |
| B | 氏名 |

## セットアップ

### 1. GASプロジェクトの準備

1. [Google Apps Script](https://script.google.com) で新しいプロジェクトを作成
2. スプレッドシートと紐付け（「拡張機能」→「Apps Script」から開くと自動紐付け）
3. `コード.gs` / `index.html` / `form.html` の内容をそれぞれ貼り付け

### 2. 設定値の変更

`コード.gs` 内の以下の箇所を環境に合わせて変更してください。

```javascript
// getRecipientData() 内
const sheetId = 'ここに宛先リストのスプレッドシートIDを入力';

// sendEmailInBackground() / sendNotificationToOperator() / sendReminders() 内
from: 'ここに送信元メールアドレスを入力'
```

### 3. Webアプリとして公開

1. GASエディタ上部「デプロイ」→「新しいデプロイ」
2. 種類：ウェブアプリ
3. 次のユーザーとして実行：自分
4. アクセスできるユーザー：組織内全員（または任意）
5. デプロイしてURLを取得

### 4. リマインダーのトリガー設定

1. GASエディタ左メニューの「時計アイコン（トリガー）」を開く
2. 「トリガーを追加」
3. 以下の通り設定して保存

| 項目 | 設定値 |
|------|--------|
| 実行する関数 | `sendReminders` |
| イベントのソース | 時間主導型 |
| タイプ | 日付ベースのタイマー |
| 時刻 | 任意（例：午前9〜10時） |

## 処理フロー

```
[送付ツール]
  ↓ 宛先・案件名を入力して送信
  ↓ 履歴シートに記録（ステータス: 処理開始）
  ↓ アンケートメールを送信

[回答者]
  ↓ メール内URLからアンケートページを開く
  ↓ 星評価5問 + コメント（任意）を入力して送信
  ↓ 履歴シートに回答を記録（ステータス: 回答済み）
  ↓ オペレーター宛に回答内容を通知メール送信

[自動リマインダー（毎日実行）]
  ↓ ステータスが「処理開始」かつ送信から3日以上経過した行を検索
  ↓ 対象者にリマインダーメール送信
  ↓ ステータスを「リマインダー送信済み」に更新
```
